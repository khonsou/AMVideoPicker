# AMVideoPicker

**3C 短视频素材评估、筛选与复测决策工具**

AMVideoPicker 将巨量云图行业内容榜的原始记录整理为可交互的素材看板，帮助团队回答三个问题：

1. 哪些视频的点击率和看完比例正在一起变好？
2. 哪些视频当前表现也足够好，而不是只有低基数增长？
3. 高双升素材的标题有哪些可复用的信息结构？

> 重要边界：本工具用于**内容质量评估与候选发现**，不直接计算真实财务 ROI，也不把平台记录的“目标行为”自动解释为咨询、下单或支付购买。

## 核心功能

### 质量优先清单

- 默认展示 **178 条点击率和看完比例同时上升的素材**。
- 可切换到 **507 条质量趋势可比素材**，或查看 **846 条素材的当前表现**。
- 主表只保留最重要的信息：
  - 点击率变化与看完比例变化
  - 当前点击率与当前看完比例
  - 看到 3 秒比例
  - 观看数据覆盖率

### 素材详情

- 优先展示质量趋势和前后 28 天对比。
- 同时展示看到 3 秒、5 秒比例、平均观看时长与数据覆盖率。
- 规模、目标行为和其他辅助信息默认折叠，不干扰主排序。
- 支持云图视频预览、键盘操作、Escape 关闭弹层与焦点回环。

### 标题学习

- 区分 **64 条高双升素材**与 **114 条低基数反弹素材**，并以 **329 条非双升素材**作为对照。
- 对比 9 类标题特征：具体优惠、功能利益、数字信息、疑问、人群场景、痛点、实测、行动引导和口语悬念。
- 展示三个代表标题、三条标题骨架与常见误区。
- 提供《高双升标题学习清单》工作簿下载，包含案例、对比图和可复算公式。

### 品牌片场

- 独立路由 `/brand-playbook`，与投放数据分析分维度使用。
- 总结正式首发片、功能介绍片、品牌符号片和生活形象片的生产方法。
- 明确 Seedance 负责自然实景，Remotion 负责转场、真实 UI 合成与精确时间线。
- 提供三级镜头接力、六轮小样流程、声音先行规则和导演反馈模板。
- 两个 H5 设有双向链接，品牌页按需加载，不需要加载数据图表模块。

### 全中文界面

界面使用以下中文指标，避免把专业缩写作为理解门槛：

- 展示次数 / 广告展示次数
- 点击率
- 点击后转化率
- 看到 3 秒、5 秒比例
- 看完比例
- 每千次广告展示目标行为数
- 观看数据可用比例

## 数据处理流程

原始 JSON 保持只读，加工结果写入 `outputs/`。主要脚本职责如下：

| 脚本 | 作用 |
| --- | --- |
| `build_video_dataset.py` | 合并主文件与补抓文件，按日期和素材去重，重建日级漏斗 |
| `score_videos.py` | 质量检查、同层基准、贝叶斯收缩、时间复核与候选分层 |
| `prepare_h5_data.py` | 计算质量、前后 28 天变化、趋势可比性与一句话解读 |
| `analyze_titles.py` | 区分高双升与低基数反弹，提取标题特征 |
| `prepare_title_insights.py` | 生成标题学习板块数据与下载文件 |
| `build_title_workbook.py` | 生成含公式和图表的标题学习工作簿 |
| `qa_title_workbook.py` | 独立核对工作簿分组、比例、公式与图表 |

## 核心算法与口径

### 1. 数据去重与缺失处理

- 同一天、同一素材只保留最大曝光记录，不重复累计。
- 未进入每日 TOP 6000 只表示缺失，**不补零**。
- 对点击率、点击后转化率、曝光级转化率和观看字段分别进行质量检查。

### 2. 前后 28 天趋势比较

前期为 2026-09-08 至 2026-10-05，后期为 2026-10-06 至 2026-11-02。

进入质量趋势榜必须同时满足：

- 前后各至少 **3 天在榜**；
- 前后各至少 **20,000 次展示**；
- 前后两期观看数据覆盖率均不低于 **50%**。

### 3. 共同改善

```text
质量趋势 = min（点击率变化，看完比例变化）
```

取两项变化中较弱的一项，避免用单项大涨掩盖另一项下降。

- **质量趋势 > 0**：点击率和看完比例同时上升。
- **质量趋势可比**：满足在榜、展示和覆盖率要求。
- **高双升**：双升且当前点击率、当前看完比例均不低于可比组中位数。
- **低基数反弹**：双升但未达到当前双高，不能直接作为创意模板。

### 4. 同层基准与保守效率（辅助分析）

在辅助分析中，素材按品类和时长建立同层基准，并使用 Beta-Binomial 收缩减少小样本偶然高转化造成的误判。

```text
pEB  = (E + κp0) / (N + κ)
LCB90 = BetaQuantile(0.05; E + κp0, N − E + κ(1−p0))
保守效率指数 = 100 × LCB90 / p0
```

其中：

- `N`：有效广告展示次数；
- `E`：平台目标行为当量；
- `p0`：同品类、同时长素材的基准转化率；
- `κ`：先验强度，当前为 10,000 次展示。

`LCB90` 表示双侧 90% 区间下限，也等于单侧 95% 下界。保守效率指数只用于候选发现，**不是 ROAS 或利润倍数**。

### 5. 标题特征识别

标题分析采用关键词命中，不是语义理解，也不证明因果关系。

可复核的观察结果包括：

- 高双升组的具体优惠占比高约 **7.2 个百分点**；
- 明确功能利益高约 **6.3 个百分点**；
- 数字信息高约 **6.0 个百分点**；
- 疑问句、人群标签、痛点词和口语悬念没有表现出稳定优势。

这些差异只用于提出新的创意假设，不能代替后续对照测试。

## 评价边界

- 广告展示量由付费投放驱动，但不等于实际花费。
- 实际花费应按下式计算：

```text
实际花费 = 广告展示次数 ÷ 1,000 × 千次展示成本
```

- 当前缺少千次展示成本、真实订单、退款和每单贡献利润，因此不能判断素材是否赚钱。
- 平台目标行为的具体含义未确认，不能直接视为有效订单。
- 点击率、看完比例和增长率也可能受到人群、报价、落地页和归因方式影响。
- 趋势改善不等于绝对优质，当前表现与数据覆盖率必须同时检查。
