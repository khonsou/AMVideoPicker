# 素材罗盘与品牌片场

响应式中文 H5 项目，包含两个相互独立的内容维度：

- **素材罗盘**：按“质量趋势、当前表现、开头留存、数据可信度”的顺序展示投放数据证据，筛选值得复测的视频。
- **品牌片场**：沉淀品牌向视频生产 Know-how，讲清片型选择、Seedance 与 Remotion 分工、六轮小样流程和实景 UI 合成。

## 运行与构建

```bash
npm install
npm run dev
npm run build
```

`npm run dev -- --host 0.0.0.0 --port 7100` 可指定监听地址和端口。生产静态文件位于 `dist/`，不需要服务端、数据库或外部数据接口。

## 页面入口

- `/`：素材罗盘数据分析看板。
- `/brand-playbook`：品牌向视频生产方法手册。
- 两个页面设有双向链接，并分别加载源码 chunk；品牌页不需要加载数据图表模块。

## 素材罗盘的信息重要度

1. **质量趋势**：点击率和看完比例是否共同改善，是主榜首要依据。
2. **当前表现**：当前点击率和看完比例，用于防止低基数上升被误读为绝对优质。
3. **开头与正文**：看到 3 秒、5 秒和看完比例，用于定位内容问题。
4. **数据可信度**：前后两期观看数据覆盖率都至少为 50%，才进入质量趋势排名。

投放量变化、投放稀释筛选、目标行为规模和复杂统计公式已从主界面及排序中移除。辅助信息在素材详情中默认折叠，不影响主榜。

## 主要功能

- 默认仅展示 178 条点击率与看完比例同时上升的素材。
- 可切换到 507 条质量趋势可比素材，或 846 条素材的当前表现。
- 主表只保留两项质量变化、两项当前表现、3 秒留存和数据可信度。
- 素材详情优先展示质量趋势，前后 28 天仅对比点击率、看完比例和 3 秒留存。
- 标题或素材编号搜索、品类筛选、指标排序和加载更多。
- 行业点击率、3 秒留存和看完比例趋势图。
- 云图预览链接、增强版表格和完整分析报告下载。
- 独立“标题学习”板块：64 条高双升与 114 条低基数反弹对照、9 类标题特征差值图、三个代表标题、三条标题骨架和常见误区。
- 可下载《高双升标题学习清单》工作簿，包含完整案例、特征对比和可复算公式。
- 独立“品牌片场”手册：四类片型、工具分工、三级镜头接力、六轮制作流程、黑屏底片与真实 UI 合成。
- 键盘操作、Escape 关闭弹层、焦点回环、触控目标和减少动态效果支持。

## 数据口径

数据窗口为 2026-08-11—2026-11-02，按付费广告业务口径处理。素材罗盘只评价内容质量，不评价预算规模或财务回报。

趋势比较使用前后两个 28 天，未进榜不补零。前后各至少 3 天在榜、展示各至少 20,000，且两期观看数据覆盖率都至少为 50%，才进入质量趋势排名。共同改善取点击率变化与看完比例变化中较弱的一项。

当前缺少真实订单、退款、每单利润和千次展示成本，因此不能判断是否赚钱。“目标行为”具体是咨询、下单还是其他行为，当前数据无法确认，故仅放在辅助信息中。
